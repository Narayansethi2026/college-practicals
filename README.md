# 🎓 College Practicals

Welcome to **College Practicals** — a learning repository created to help BCA students prepare for college practical examinations.

## 📚 Subjects Covered

* **C++ OOPs:** Programs and practical exercises.
* **Web Development (WD):** HTML, CSS, JavaScript and practical projects.
* **DB Python:** Python programs, SQLite database operations, CSV handling and related practicals.

## 🎯 Repository Goals

* Organize college practical questions and solutions in one place.
* Help students revise programs before practical examinations.
* Share learning resources and improve programming skills.
* Encourage collaboration and learning through GitHub.

## 📁 Repository Structure

* `C++-OOPs/` — C++ practical programs
* `WD/` — Web development practicals
* `DB-Python/` — Python and database practicals

*Folder contents may be updated as new practicals are added.*

## 🚀 How to Use

1. Browse the subject folders.
2. Open the program or practical you need.
3. Read the code and try running it on your computer.
4. Practice independently to strengthen your concepts.

## 🤝 Contributions

Suggestions, corrections and improvements are welcome. Let's learn and grow together!

## ⚠️ Disclaimer

This repository is intended for educational purposes. Always follow your college's academic guidelines and verify programs before using them.
